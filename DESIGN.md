# Capman Design System

## Visual Direction

Product UI for a precise, evidence-led cognitive-workflow tool. The default
experience is a calm Personal workspace; Team Library is a deliberately
separate, permissions-gated scope.

## Color

- Canvas: `#0B0D10`
- Sidebar: `#15181D`
- Surface: `#1E232A`
- Primary / active / focus: `#2962FF`
- Success: `#00B894`
- Attention: `#F5A623`
- Risk: `#F04545`
- Primary text: `#E6E9EE`

Use cobalt only for the current selection, focus, and primary actions. Use
semantic colors only for their state; they are not decoration.

## Typography

Use the system sans stack. Product type uses a fixed scale, strong contrast
between headings and metadata, readable 1rem body text, and tabular figures
where data alignment matters.

## Layout

Desktop uses a persistent left sidebar and a single task-focused workspace.
Navigation is grouped into work surfaces and lower utility actions. Mobile uses
a compact horizontal navigation rail while preserving every personal surface.
Session investigation is queued to use an evidence timeline with a
reusable-outcome rail at wide sizes.

## Interaction

Every control has visible focus, keyboard access, loading/empty/error states,
and reduced-motion behavior. Team Library never displays private material and
is unavailable until the sharing backend exists.
